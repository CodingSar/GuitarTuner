## concern/security-web

- SEC-001 MUST: Serve a default-deny Content-Security-Policy with script-src 'self', style-src 'self', connect-src 'none', object-src 'none', base-uri 'none' and form-action 'none'.
- SEC-003 MUST: After each production build, confirm the output has no inline script or style and no eval or Function call, and write the policy to match the output.
- SEC-004 MUST: Send frame-ancestors 'none' as a response header only, and record clickjacking as unmitigated when the host cannot send headers.
- SEC-005 MUST: Send Permissions-Policy with microphone=(self) and disable unused features with an empty list, such as camera=() and geolocation=().
- SEC-006 MUST: Never send microphone=() for this app, because it disables the microphone for the app's own origin.
- SEC-007 MUST: Load no third-party scripts, styles, fonts or frames, and grant no iframe allow attributes; if a third-party file is ever added, require Subresource Integrity with CORS.
- SEC-008 SHOULD: Start Strict-Transport-Security at max-age=31536000 and add includeSubDomains and preload only after every subdomain is confirmed to serve HTTPS.
- SEC-009 MUST: Set Referrer-Policy to strict-origin-when-cross-origin explicitly, as a response header or a meta element.
- SEC-010 MUST: Send X-Content-Type-Options: nosniff and Cross-Origin-Opener-Policy: same-origin as response headers.
- SEC-011 SHOULD: Add require-trusted-types-for 'script' to the Content-Security-Policy once the source tree has no string sinks, and with no trusted-types allowlist.
- SEC-013 MUST: Render text with textContent, createElement, setAttribute for non-executable attributes, or canvas fillText, and never with markup strings.
- SEC-016 MUST: Treat location.hash, query strings, storage and file inputs as untrusted; parse stored data with JSON.parse and validate it against an allowlist before use.
- SEC-017 MUST: Add no window message listener unless a feature needs one; if one is added, check event.origin and event.source, validate the message syntax, and send with an exact targetOrigin, never "*".
- SEC-020 MUST: Run npm audit in CI as an advisory gate, and do not treat a clean audit as proof that dependencies are safe.
- SEC-021 SHOULD: Review dependency advisories through a vulnerability-management process, because scanners miss issues that have no CVE and keep flagging patched versions.
- SEC-022 MUST: Declare permissions in every workflow file, with contents: read at the top level and write scopes granted per job only.
- SEC-025 SHOULD: Pass untrusted expression values into workflow steps through environment variables, not by interpolating them into inline scripts.
- SEC-027 MUST: Publish security.txt over HTTPS under /.well-known/ with a Contact field and an Expires field less than one year away, and resolve where a project site's /.well-known/ path sits before publishing.
- SEC-028 MUST: Write a privacy notice that names the host's IP logging, lists every browser storage key the app writes, explains how to clear it, and avoids the claim that nothing is collected.

## domain/music-training

- DOM-007 MUST: Detect pitch with an autocorrelation-family method (YIN or McLeod), not the strongest FFT bin, because the strongest bin is often a harmonic.
- DOM-009 MUST: Show "no reliable pitch" instead of a note name or cents value when the detector's clarity is below the gate.
- DOM-012 SHOULD: Expose the in-tune window as a setting, defaulting to plus or minus 5 cents, and do not present that default as a standard.
- DOM-015 MUST: Treat a muted microphone track as distinct from an ended track, and tell the player which one applies.
- DOM-016 SHOULD: Request echoCancellation, noiseSuppression and autoGainControl as ideal false, then read track.getSettings() and show the values in effect.
- DOM-017 MUST: Keep microphone audio on the device and store or send nothing without a separate user action.
- DOM-019 MUST: Schedule audio ahead with a short timer and lookahead window, and never use the raw timer callback time for playback.
- DOM-022 MUST: Provide a visual offset control that moves note drawing without changing hit windows.
- DOM-024 SHOULD: Ramp the drawn speed over about 150 to 300 ms when the speed toggle changes, so no note jumps mid-flight.
- DOM-025 MUST: Keep a playback-rate control separate from the visual speed control, and label each one.
- DOM-026 MUST: Show the hit window in milliseconds on the practice screen, and keep it fixed for a given difficulty.
- DOM-027 SHOULD: Make the early side of a hit window no wider than the late side, because audio that leads is detected at shorter offsets than audio that lags.

## lang/typescript

- TS-015 SHOULD: Use `satisfies` to check an object literal against a type while keeping its specific inferred types.
- TS-018 MUST: Put `tsc --noEmit` in the build script before `vite build`, because Vite only transpiles.
- TS-019 MUST: Run tests with `vitest run` in CI and check scripts, never bare `vitest` watch mode.
- TS-026 SHOULD: List the ambient types the code needs in tsconfig `types`, because TypeScript 6.0 defaults `types` to an empty array.
